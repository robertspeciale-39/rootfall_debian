      How BOOKWORM works
      Same habits as a real round.

      The loop

      • New to Linux? Do Mission 00: First Steps first. It teaches the handful of commands everything else uses, and nothing in it can break the machine.
      • Pick Guided or Competition on the Missions page. Guided shows a coach for every task: where to look, then how to fix it, then a shortcut. Coaching is free. Competition keeps short hints (4 points each) and a ranked score.
      • Each mission is a Debian 12 image with planted problems from one checklist category.
      • Type readme (or cat ~/Desktop/README.txt) first. It says who is authorized and which services must stay up.
      • Fix things with real commands. The Scoring Report updates after every command, just like the scoring report on a competition image.
      • Breaking the README costs points: deleting an authorized user, stopping SSH, blocking SSH with the firewall, breaking sudo.
      • Tasks marked BONUS are the hardest. You can Clear a mission without them, and you still get an A. Finish them too for an S.

      Competition rank starts from your percent of required points. Each hint costs 4, and going over par costs up to 15. Bonus tasks only matter for the S. Replay a mission to improve your rank. Your best rank is kept until you close the tab.

      Debian 12 is not Mint

      • /usr/sbin is not on a normal user's PATH. ufw, usermod and sysctl say "command not found" without sudo.
      • No /var/log/auth.log, because rsyslog is not installed. Use sudo journalctl.
      • No ufw, pwquality or auditd until you install them. No netstat. No Snap.
      • GDM3 settings are in /etc/gdm3/daemon.conf, and AppArmor is on by default.

      Coming from Mint or Ubuntu?

      • Files app (Nemo) = ls, cd, pwd. Text Editor = nano. Right-click Open as Root = sudo.
      • Update Manager and Software Manager = sudo apt update, sudo apt full-upgrade, sudo apt install.
      • Users and Groups = deluser, usermod, gpasswd. Firewall Configuration = ufw (not installed on Debian until you add it).
      • Login screen settings: Mint uses LightDM, Debian 12 uses GDM3 and /etc/gdm3/daemon.conf.

      Shell tips

      • Tab completes commands and file names. Up/Down walks your history. In Guided mode, click a grey command in the Coach panel to type it for you.
      • Pipes, >, >>, && and ; all work. sudo echo x >> file fails, just like on a real system.
      • nano FILE opens an editor. Ctrl+O saves (nothing else to confirm here), Ctrl+X exits, Ctrl+K cuts a line, Ctrl+U pastes it. The Where Is button finds text. Without sudo you cannot save system files.
      • Progress is not saved. Closing or refreshing the tab starts you over, the same as a fresh image.
